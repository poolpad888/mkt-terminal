# FINFACTS — памятка по выкатке

## Обновить на сервере

    cd /opt/finfacts && git pull && systemctl restart finfacts

Если менялся файл службы сборщика:

    cd /opt/finfacts && git pull && cp tg/finfacts-tg.service /etc/systemd/system/ && systemctl daemon-reload && systemctl restart finfacts-tg finfacts

## Проверить после выкатки

Быстрая проверка живого сайта — все страницы, адреса API, сжатие, отметки версии:

    bash tests/smoke.sh https://finfacts.ru

Должно закончиться строкой «ВСЕ ПРОВЕРКИ ПРОЙДЕНЫ». Если есть провалы — в выводе видно, что именно.

Журнал службы:

    journalctl -u finfacts -f
    journalctl -u finfacts --since "-10min" --no-pager | grep -E "BUILD|DEDUP|OFFTOPIC|TSY|NAS|fail"

Что смотреть в журнале:
- `BUILD: okSources=N/M` — сколько источников ответили;
- `DEDUP: … за N мс` — время склейки дублей, в норме сотни миллисекунд;
- `OFFTOPIC: убрано N` — сколько новостей отсеяно как не по теме;
- `TSY: получено 4 из 4` и `NAS: …` — доходности и Nasdaq подтянулись.

## Проверка интерфейса в браузере (только на машине разработки)

Нужен Python с playwright. Данные ленты и панели подменяются на тестовые,
внешние источники не нужны.

    PORT=10092 node server.js &
    python3 tests/ui.py

## Файлы с данными (не в git, живут рядом с server.js)

- `stats.json` — статистика посещений;
- `shares.json` — короткие ссылки на наборы котировок;
- `first-seen.json` — время первой встречи записей без даты.

Все три создаются сами; при переносе на другой сервер их можно скопировать,
а можно и не копировать — сайт заведётся с нуля.

## Переменные окружения

- `PORT` — порт службы (по умолчанию 10000);
- `DATABASE_URL` — строка Postgres для архива (необязательно);
- `TG_API_ID`, `TG_API_HASH` — ключи Телеграма для сборщика.

## Версия сайта

Файл `public/version.json`: номер, дата, список изменений и история. Показывается
в шапке рядом с LIVE. При обновлении — поднять номер и вписать изменения.
Просьба «обновите страницу» у открытых вкладок работает независимо от этого
файла: она сравнивает отпечаток самой страницы.
